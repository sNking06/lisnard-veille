# Politique de neutralité
- Ton factuel, aucun jugement sur la personne, uniquement sur la faisabilité des mesures.
- Citations courtes, pas de republication des vidéos (lecteurs officiels uniquement).
- Toute donnée chiffrée cite une source consultée, sinon « non établi ».
- Mention visible : « analyse générée par IA, peut contenir des erreurs ».
